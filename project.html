客户面临的问题

  • 操作系统权限分散 没有批量操作工具
  • 各种业务监控 agent 无法统一
  • 现有 zabbix 监控系统使用 mysql 作为后端时常出现 mysql 数据库性能问题
  • 现有 zabbix 监控展现方式单一

项目范围/解决方案：

  • 通过开源技术构建的基础架构监控
  • 收集各项底层 os，db 等运行数据主要用于故障问题定位
  • 通过 Ansible 脚本实现监控虚拟机，数据库等批量接管

案例总结

方案围绕基础架构监控展开，收集操作系统、数据库等运行数据以支持故障定位，并通过 Ansible 脚本进行监控虚拟机和数据库的批量接管。
